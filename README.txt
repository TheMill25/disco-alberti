LABORATORIO WEB - DISCO DE ALBERTI

REQUISITOS
- Python 3.10 o superior
- Flask

INSTALACIÓN (Windows)
1. Extrae el archivo ZIP.
2. Abre la carpeta disco_alberti_web en Visual Studio Code.
3. Abre una terminal dentro de esa carpeta.
4. Ejecuta: py -m venv venv
5. Ejecuta: venv\Scripts\activate
6. Ejecuta: pip install -r requirements.txt
7. Ejecuta: py app.py
8. Abre en el navegador: http://127.0.0.1:5000

La aplicación tiene pestañas separadas para CIFRAR y DESCIFRAR.
Para probar: escribe un mensaje, cifra, usa el botón "Usar este resultado en DESCIFRAR"
y descifra manteniendo exactamente los mismos parámetros de configuración.

NOTA ACADÉMICA
La variante irregular por clave es experimental y sirve para demostración.
No debe utilizarse para proteger información real.
